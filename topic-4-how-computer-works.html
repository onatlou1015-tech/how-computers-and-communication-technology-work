How a Computer Works

The IPO+S model, the fetch–decode–execute cycle, binary data, and how a simple task flows through the system.

The IPO+S Model

In Topic 1, you learned that every computer system performs four main functions: Input, Process, Storage, and Output. This pattern is called the IPO+S model, and it is the foundation of how every computer works — from the smallest smartwatch to the most powerful supercomputer.

IPO+S stands for Input → Process → Output → Storage. It describes the flow of data through a computer system. Data enters as input, is worked on during processing, is shown or sent out as output, and is saved in storage for later use.

Input

Data comes into the computer from the user or another device.

Process

The CPU works on the data — calculating, comparing, and transforming it.

Output

The results are shown to the user through a screen, speaker, or printer.

Storage

Data is saved for later — in RAM temporarily, or on disk permanently.

Why the Order Matters

Notice that in the IPO+S model, storage comes last — after output. This is because storage is about saving data after it has been processed and shown. However, storage also interacts with the other steps in two important ways:

  • Before processing: Data and programs must be loaded from storage into RAM before the CPU can work on them.
  • After processing: The results are saved to storage so they are not lost when the computer turns off.

So the full picture is a cycle, not a straight line. Data is loaded from storage, becomes input, is processed, is output, and is saved back to storage — ready to be used again next time.

Analogy: Think of doing homework. You take out your notebook from your bag (load from storage). You read the question (input). You think about the answer (process). You write the answer (output). Finally, you put the notebook away in your bag (store). That is exactly how a computer handles data.

The Fetch–Decode–Execute Cycle

The IPO+S model describes the big picture of how data flows through a computer. But how does the CPU actually do the processing? The answer lies in a repeating pattern called the fetch–decode–execute cycle.

This cycle happens inside the CPU billions of times every second. Every instruction your computer carries out — opening an app, playing a video, saving a file — is made up of thousands or millions of these tiny cycles.

Step 1 — Fetch

The CPU fetches (retrieves) the next instruction from memory. Every program is stored as a list of instructions, and the CPU keeps track of which one comes next using a special counter. The instruction is brought into the CPU so it can be worked on.

Step 2 — Decode

The CPU decodes the instruction — that is, it figures out what the instruction means. Instructions are written in machine code, which is a pattern of 0s and 1s. The CPU translates that pattern into an action, such as "add these two numbers" or "move this data to a different location".

Step 3 — Execute

The CPU executes the instruction — it actually carries out the action. This might mean performing a calculation, comparing two values, moving data, or jumping to a different part of the program.

Step 4 — Store

The CPU stores the result. The result might be written back into a register inside the CPU, saved into RAM, or sent to another component like the GPU or a storage drive. Once the result is stored, the CPU is ready to fetch the next instruction, and the cycle begins again.

Analogy: Imagine you are following a recipe. Fetch = reading the next step on the recipe card. Decode = understanding what the step means ("chop the onions"). Execute = actually chopping the onions. Store = putting the chopped onions in a bowl and moving on to the next step. Just like a chef repeats these steps for every ingredient, the CPU repeats this cycle for every instruction.

Why This Cycle Matters

The speed of this cycle is one of the main things that determines how fast a computer feels. Modern CPUs can complete billions of fetch–decode–execute cycles every second. This is why a modern computer can play high-definition video, run complex games, or handle thousands of calculations at once — it is simply repeating this simple cycle at an incredible speed.

How Data Is Represented in a Computer

Here is something surprising: computers do not understand letters, pictures, or sounds. Deep inside the CPU, everything is stored and processed as only two values — 0 and 1. This system is called binary.

Binary — The Language of 0s and 1s

Inside a computer, there are millions of tiny electronic switches called transistors. Each transistor can be in one of two states: off or on. We represent "off" as 0 and "on" as 1. This is why computers use binary — it matches the physical reality of the electronic switches inside them.

A single 0 or 1 is called a bit (short for "binary digit"). A bit is the smallest unit of data in a computer.

Bits and Bytes

A single bit does not carry much information — just one 0 or one 1. To represent something useful, computers group bits together. The most common group is 8 bits, which is called a byte.

How Binary Represents Everything

Using only 0s and 1s, computers can represent every kind of data:

  • Numbers: The decimal number 5 becomes 0101 in binary.
  • Letters: The letter "A" is represented as 01000001 using the ASCII code.
  • Images: Each pixel's colour is stored as three numbers (red, green, blue), each in binary.
  • Sound: A sound wave is sampled thousands of times per second, and each sample is stored as a number in binary.
  • Video: A video is just many images shown in rapid sequence, each one made of binary numbers.

Analogy: Think of binary like a very simple language with only two words — "yes" and "no". With just those two words, you can answer any yes/no question. By asking many questions in a row, you can communicate anything. That is exactly how a computer uses bits to represent everything.

How a Simple Task Flows Through the System

Now let us put everything together. We are going to trace exactly what happens when you press the letter "A" on your keyboard and it appears on your screen and gets saved to a file. This one simple action involves every part of the computer working together.

Step 1 · Input
You press the "A" key
The keyboard detects the press and converts it into an electrical signal. That signal is encoded into a binary code — the ASCII value for the letter "A", which is 01000001.
Step 2 · Travel
The signal travels to the CPU
The signal travels through the motherboard to the CPU. The motherboard acts as the highway that carries data between all the components.
Step 3 · Process (Fetch)
The CPU fetches the next instruction
The CPU looks in memory for the next instruction. It finds one that says "read the keyboard input and display it".
Step 4 · Process (Decode)
The CPU decodes the instruction
The CPU figures out what the instruction means. It understands that it needs to take the incoming keyboard data and send it to the screen and to the file.
Step 5 · Process (Execute)
The CPU executes the instruction
The CPU carries out the action. It sends the character "A" (as binary) to the GPU so it can be displayed, and to RAM so it can be held while you keep typing.
Step 6 · Storage
Data is stored temporarily in RAM
While you continue typing, all the characters — including the "A" — are held in RAM. This is temporary storage. If the power went out now, the text would be lost.
Step 7 · Output
The "A" appears on your screen
The GPU converts the binary data into an image of the letter "A" and sends it to the monitor. You see the letter appear on the screen in real time.
Step 8 · Storage (Permanent)
You save the file — data goes to permanent storage
When you press Ctrl+S (or Save), the data moves from RAM to the hard drive or SSD. This is permanent storage. The next time you open the file, the "A" will still be there, waiting to be loaded back into RAM.

What This Shows Us

A single keystroke looks simple, but behind the scenes it involves hardware (keyboard, motherboard, CPU, RAM, GPU, monitor, storage), software (the operating system, the text editor), and the IPO+S model working together. Every action you take on a computer follows a similar path. Understanding this flow is the heart of understanding how a computer works.
