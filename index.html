Grade 8 · Unit Overview

Inside the Machine:
How Computers & Communication Technology Work

From hardware to networks — discover how data flows, devices connect, and technology solves real‑world problems.

Unit Overview. This unit teaches Grade 8 students how computer systems are built and how they function, and how communication technology connects devices and people. Students move from identifying components (hardware and software) to understanding working principles (how data flows, how networks communicate), and finally to applying this knowledge to solve basic real-life problems.

The unit is designed to be hands-on and inquiry-based. Students disassemble ideas (not necessarily machines), trace how data moves, and use their understanding to troubleshoot and make decisions about technology.

Learning outcomes

Knowledge (Understand)

  • Identify the main components of a computer system (hardware and software).
  • Describe the function of key hardware parts (CPU, RAM, storage, motherboard, input/output devices).
  • Explain the difference between hardware and software, and between system software and application software.
  • Describe the basic working principle of a computer: input → process → storage → output.
  • Explain how communication technology works (networks, internet, protocols, wireless).
  • Distinguish between different types of networks (LAN, WAN, Wi-Fi, mobile networks).

Skills (Do)

  • Trace how data flows through a computer system when performing a task.
  • Compare different types of computers and communication tools for different purposes.
  • Troubleshoot basic computer or connectivity problems using system knowledge.
  • Apply understanding of components to recommend a device for a specific need.
  • Demonstrate how devices communicate over a network (e.g., sending a message, sharing a file).

Attitudes (Value)

  • Appreciate how computer systems and communication technology solve real-world problems.
  • Show curiosity about how technology works.
  • Collaborate with peers to investigate and solve problems.
  • Use technology responsibly and safely (connecting to Indicator 4).
